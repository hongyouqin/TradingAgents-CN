## 重新安装tradingagents-backend镜像
### 1. 停止并删除旧容器
docker stop tradingagents-backend
docker rm tradingagents-backend

### 2. （可选）删除旧镜像，确保使用最新代码构建
docker rmi hsliup/tradingagents-backend:latest

### 3. 清理构建缓存（释放空间，避免使用旧缓存）
docker builder prune -f

### 构建镜像
sudo docker-compose up -d --build backend

### 导入初始化配置
docker exec -it tradingagents-backend python scripts/import_config_and_create_user.py /app/install/database_init_export_config.json --skip-user

### 下载容器里的日志到本地
docker cp tradingagents-backend:/app/logs/tradingagents.log ./tradingagents.log
